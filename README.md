## Put it online with GitHub Pages (free)

1. Create a free account at github.com and tap New repository.
2. Name it, for example: adesh-saee-wedding. Keep it Public. Tap Create.
3. Tap "uploading an existing file", select ALL the files above, and tap Commit changes.
4. Open Settings > Pages. Under Branch, choose "main" and "/ (root)", then Save.
5. After a minute, your link appears at the top of the Pages screen:
   https://YOUR-USERNAME.github.io/adesh-saee-wedding/

Send that link to your guests. They do not need any account.

To change anything later, edit index.html on GitHub (pencil icon) and commit.

## Languages

The invitation opens in Marathi first. There is a मराठी / English switch at the top right of the first page and at the bottom of the page.
- Normal link (opens in Marathi): https://YOUR-USERNAME.github.io/adesh-saee-wedding/
- English link (opens directly in English): https://YOUR-USERNAME.github.io/adesh-saee-wedding/#en
